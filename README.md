# QFHPS — A Hybrid Interstellar Propulsion Concept
## Technical study, version 5.0 (2026)

**A concept specification** by Maciej Łuczewski: a hybrid interstellar drive combining a
**Casimir vacuum modulator** (reinterpreted geometrically as a controlled local deformation
of the spacetime metric — "falling in spacetime") with a **magnetic Bussard scoop** serving
as power generator, maneuvering drive and magnetic sail brake (Zubrin–Andrews, 1991).

Built on laboratory-confirmed physics — the static and dynamical Casimir effect, neutrino
cooling (the volumetric heat-rejection channel of every neutron star), the hot CNO cycle of
classical novae — with an explicit certainty status for every claim: **[F]** confirmed physics,
**[E]** engineering extrapolation, **[S]** speculation. Includes honest order-of-magnitude
accounting, a reference ship design in the convention of Project Daedalus/Icarus, a staged
program of ten experiments (starting with a deliberately low-cost asymmetric Casimir cavity
measurement) and four observational predictions whose failure falsifies the corresponding
elements of the concept.

For the hard-SF reader: dessert. For the engineer and the student: an invitation to calculate
better. For whoever one day builds such a drive: a seed.
